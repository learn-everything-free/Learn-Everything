# Prompt Versioning and Evals

A prompt that works is an asset; a prompt nobody can reproduce is a liability. LLMOps borrows two habits from software engineering: commit every prompt version to git, and before shipping a change, run it past a set of test cases — an eval — and record the score.

## What you'll practice

- **Version Your Prompts in Git** — practice · beginner
- **Write an Eval Results File** — challenge · beginner

## A command you'll meet

```bash
git commit -m "v1 prompt"
```
