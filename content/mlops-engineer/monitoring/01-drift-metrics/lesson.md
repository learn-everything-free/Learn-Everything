## A command you'll meet

```bash
echo accuracy=0.87 > metrics.txt
```

A model without a logged metric is a claim without evidence. A model whose metric is
never re-checked is a claim that quietly expires. These two tasks are the smallest
honest monitoring loop. Open any task below for the full walkthrough.
